TARIFF ANALYZER — инструкция по сбору диагностики
====================================================

Приложение раньше запускалось "молча" — без окна и без ошибок. В этой сборке
добавлена диагностика, которая поможет понять причину. Пожалуйста, выполните
шаги по порядку и пришлите разработчику всё, что получится собрать —
даже если какой-то шаг не даст результата, это тоже важная информация.


ШАГ 0. Проверьте путь без кириллицы (самая быстрая проверка)
----------------------------------------
Скопируйте всю папку с программой в путь, где нет русских букв — например:

    C:\Temp\TariffAnalyzer

(Win+R -> "C:\Temp" -> Enter, если папки нет — создайте её сама Windows
позволит без прав администратора). Запустите оттуда. Если ваше имя
пользователя Windows на кириллице (например, C:\Users\Иванов\...) — это
тоже может быть причиной, даже если сама папка с программой на латинице,
т.к. под капотом используется путь к профилю пользователя.

Если из C:\Temp\TariffAnalyzer программа запустилась — сообщите об этом,
проблема найдена (нужно просто выбрать путь без кириллицы), дальнейшие шаги
можно пропустить.

Если не запустилась — переходите к шагу 1.


ШАГ 1. Запустите через Diagnostics.bat
----------------------------------------
В этой же папке лежит файл "Diagnostics.bat". Запустите ЕГО (не .exe напрямую),
дважды кликнув по нему.

 - Он запустит приложение и весь вывод сохранит в файл diagnostics_output.txt
   рядом с собой.
 - После завершения работы приложения (или сразу, если оно не запустилось)
   появится окно с кодом завершения — не закрывайте его, сфотографируйте
   или скопируйте текст.
 - Пришлите разработчику файл diagnostics_output.txt.

Если ДАЖЕ Diagnostics.bat ничего не делает (окно консоли не появляется
вообще ни на секунду) — это важный признак: скорее всего, запуск блокируется
политикой безопасности (антивирус/AppLocker/EDR) на уровне операционной
системы, ещё до старта самого приложения. Переходите к шагу 3.


ШАГ 2. Найдите лог-файл приложения
----------------------------------------
Если приложение всё же успело запуститься (хотя бы на долю секунды), оно
само пишет подробный лог в папку:

    %LOCALAPPDATA%\TariffAnalyzer\logs

Чтобы открыть эту папку — нажмите Win+R, вставьте путь выше и нажмите Enter.
Внутри будут файлы вида startup_2026-07-02_12-30-00.log — пришлите
разработчику последний по времени файл.

Если этой папки нет вообще — значит, до кода приложения дело не дошло,
это тоже важно сообщить.


ШАГ 3. Проверьте, не заблокирован ли файл Windows
----------------------------------------
1. Кликните правой кнопкой мыши по "Tariff Analyzer.exe".
2. Выберите "Свойства".
3. Внизу вкладки "Общие" посмотрите, нет ли строки
   "Этот файл был получен с другого компьютера, и его запуск может быть
   заблокирован..." с галочкой "Разблокировать".
4. Если такая галочка есть — сообщите об этом разработчику (ставить её
   самостоятельно не нужно, это тоже диагностическая информация).


ШАГ 4. Журнал событий Windows (если шаги 1-2 ничего не дали)
----------------------------------------
1. Нажмите Win+R, введите eventvwr.msc, нажмите Enter — откроется
   "Просмотр событий".
2. Слева раскройте: Журналы Windows -> Приложение (Application).
   Найдите события примерно в то время, когда вы пытались запустить
   приложение (Источник может быть "Application Error", ".NET Runtime"
   и т.п.). Сделайте скриншот.
3. Также слева раскройте: Журналы приложений и служб -> Microsoft ->
   Windows -> AppLocker (или CodeIntegrity). Проверьте, нет ли записей
   о блокировке запуска примерно в это же время. Сделайте скриншот.

Если этих разделов нет в дереве слева, или у вас нет прав их открыть —
просто сообщите об этом, это тоже результат.


ЧТО ПРИСЛАТЬ РАЗРАБОТЧИКУ
----------------------------------------
1. Файл diagnostics_output.txt (шаг 1).
2. Последний файл из %LOCALAPPDATA%\TariffAnalyzer\logs (шаг 2), если есть.
3. Было ли поле "Разблокировать" в свойствах .exe (шаг 3).
4. Скриншоты из Журнала событий (шаг 4), если получилось их найти.
5. Есть ли на компьютере права локального администратора и просят ли
   стандартные приложения (не от Microsoft) подтверждение при запуске.

Спасибо за помощь в диагностике!
